# Kunlik Reja: APK yig'ish

1. github.com da akkaunt oching (bepul).
2. Yangi repozitoriy yarating: **New repository**, nomi `kunlik-reja`, **Private** tanlang, **Create repository**.
3. **uploading an existing file** havolasini bosing. Zip'ni oching va ichidagi hamma narsani (`.github` papkasi bilan) oynaga sudrab tashlang. **Commit changes** tugmasini bosing.
4. **Actions** bo'limiga o'ting. «APK yig'ish» ishi o'zi boshlanadi (5–10 daqiqa). Yashil belgi chiqsa, ish tugagan.
5. Tugagan ishni bosing, pastdagi **Artifacts** ostida `Kunlik-Reja-APK` ni yuklab oling. Zip ichida `app-debug.apk` bor.
6. APK'ni telefonga o'tkazing va oching. Telefon «noma'lum manba»ga ruxsat so'rasa, ruxsat bering.
7. Ilova ochilganda bildirishnoma ruxsatini bering. Budilnik shu ruxsat bilan ishlaydi.

Eslatma: budilnik keyingi 7 kun uchun qo'yiladi. Ilovani haftada kamida bir marta oching.
